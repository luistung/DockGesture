# DockGesture 应用图标设计规格

日期：2026-08-13  
状态：视觉方向已确认，等待书面规格复核

## 1. 设计方向

采用用户在视觉比较页中选定的 `A1 · 蓝紫效率工具`。图标以“Dock 上的点击动作”为唯一核心隐喻，不叠加 Command 符号、退出箭头、文字或其他次要功能标记。

图标应传达：

- 它是面向 macOS Dock 的工具；
- 它通过点击手势改变 Dock 行为；
- 它是克制、可靠且现代的效率工具。

## 2. 视觉构成

### 2.1 底板

- macOS 风格圆角方形底板，1024 × 1024 源画布。
- 主色为左上蓝色到右下紫色的轻微对角渐变。
- 蓝色基准为 `#1D7CFF`，紫色基准为 `#6F52EF`。
- 允许极轻的内高光和外部空间感，但不得使用拟物纹理、玻璃反射或厚重投影。
- 图形必须在系统图标网格中保留安全边距，不触碰画布边缘。

### 2.2 Dock 图形

- 画面下部为白色圆角 Dock 轮廓。
- Dock 内包含三个简化的白色应用方块；第一个为实白，其余可降低不透明度以形成层次。
- Dock 轮廓与内部方块均使用圆角，不模拟真实第三方应用图标。

### 2.3 点击图形

- 画面中心偏上为白色向下箭头，指向 Dock。
- 箭头由垂直杆与两侧斜线构成，端点和转角圆润。
- Dock 上方的落点为黄色圆点，基准色 `#FFE45F`，带白色描边。
- 黄色是唯一强调色，不在其他部位重复。

## 3. 小尺寸规则

图标必须针对 macOS 标准尺寸输出，而不是只缩放一张复杂位图：

- 16px 和 32px：加粗 Dock 外框与箭头，减少透明层次；三个应用方块保持可辨识，点击圆点不得小于视觉上的 3px。
- 64px 和 128px：保留完整构成，限制细微阴影。
- 256px、512px 和 1024px：允许轻微渐变、内高光和克制的空间感。

所有尺寸不得出现模糊半像素边缘、细线断裂或黄色落点消失。

## 4. 制作路线

采用确定性矢量绘制：

1. 创建可维护的源 SVG；
2. 用系统或工作区可用的矢量渲染工具输出 1024px 主 PNG；
3. 为小尺寸生成必要的简化变体；
4. 生成完整 `.iconset`；
5. 使用 `iconutil` 生成 `DockGesture.icns`。

不使用生成式位图作为最终源文件。理由是该图标由简单几何形状组成，矢量路线能精确控制网格、描边、颜色和所有尺寸的一致性。

## 5. 工程接入

- 保存源文件 `Resources/AppIcon/DockGesture.svg`。
- 保存预览文件 `Resources/AppIcon/DockGesture-1024.png`。
- 生成 `Resources/DockGesture.icns`。
- `Info.plist` 增加 `CFBundleIconFile`，值为 `DockGesture`。
- 构建脚本将 `.icns` 复制到应用的 `Contents/Resources`。
- 应用版本更新为 `1.0.2`，构建号更新为 `3`。
- 新产物为 `outputs/DockGesture-1.0.2.app` 和 `outputs/DockGesture-1.0.2.zip`，不覆盖已交付版本。

菜单栏运行状态图标继续使用单色 SF Symbols；彩色应用图标只用于 Finder、应用程序文件夹、权限列表和其他系统应用身份展示。

## 6. 验证

- SVG 能被标准渲染器打开且无缺失资源。
- 主 PNG 为 1024 × 1024，颜色空间和透明通道有效。
- `.icns` 包含 macOS 所需尺寸，`iconutil` 可反向解包。
- 16px、32px、128px、512px 和 1024px 预览中主体均居中，Dock、箭头和落点可辨识。
- `Info.plist` 中图标字段正确，构建后的应用内存在 `Contents/Resources/DockGesture.icns`。
- 应用通过签名验证，核心 33 项功能检查继续通过。
- 压缩包完整且版本号为 1.0.2。

## 7. 验收标准

满足以下条件即完成：

1. 最终图标与已确认的 A1 蓝紫方向一致；
2. 不包含文字、Command 标记或退出符号；
3. 小尺寸仍能辨识 Dock、点击箭头和黄色落点；
4. 源 SVG、预览 PNG 和 ICNS 均保存在项目中；
5. DockGesture 1.0.2 使用新图标并通过构建、测试和签名验证。
